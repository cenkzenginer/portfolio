01 — Featured project Erişim — WCAG 2.2 accessibility scanner

2026 · Active

Context

Presidential Circular 2025/10 requires covered institutions in Turkey — public bodies, municipalities, universities, private hospitals, banks, e-commerce sites and more — to bring their websites and mobile apps in line with WCAG 2.2 and the Ministry of Family and Social Services checklist.

What it does

Erişim (“access” in Turkish) is a command-line tool that crawls a website politely, runs axe-core on every page, checks linked PDFs, and produces a Turkish accessibility report as JSON, a single-file HTML page and a tagged PDF. It is the scanning and reporting core of the accessibility audit and remediation service I offer to institutions in Turkey.

Scope

Automated tools detect only part of all accessibility problems — typically 30–40% of WCAG issues — so the report complements manual testing. It is not a legal opinion or a certificate of conformance.

Pipeline

  1. 01 Crawl the site
  2. 02 Run axe-core on every page
  3. 03 Check linked PDFs
  4. 04 Turkish report JSON · HTML · tagged PDF
